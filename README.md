## Контрольные вопросы
1. Почему программа может узнать имя компьютера, хотя вы не писали его в
коде?
Потому что оно изначально заведено в систему
2. Какую роль играет операционная система, когда программа запрашивает у
неё сведения?
Управляет доступом
к процессору, памяти, файлам.
3. Что означает «64-битнаяОС»?
Операционная система с разрядностью в 64бит
4. Что показывает Environment.ProcessorCount и обязательно ли это число
совпадает с числом физических ядер?
Показывает количество процессоров, которое не обязательно совпадает с числом физических ядер
5. Чем память процесса (WorkingSet) отличается от всей оперативной памяти
компьютера?
Оперативная память это общая память компьютера используемая для процессов, а память процесса это часть ОП которую в данный момент задействует процесс
6. Почему одна и та же программа без изменений вк оде может показать разные
результаты на разных компьютерах?
Результат разный при одинаковом коде из-за разности в комплектующих компьютеров
